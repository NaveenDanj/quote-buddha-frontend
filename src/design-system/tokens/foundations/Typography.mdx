# Typography

IBM Plex Serif for reading, IBM Plex Sans for the interface, IBM Plex Mono for citation IDs. Sinhala fonts sit at the end of each stack as fallbacks. Reading, large reading and Pali sizes follow `--reading-scale` (0.9, 1, 1.15, 1.3).

The Pali line must show `ṃ ñ ṇ ṭ ḍ ḷ ṅ ā ī ū` correctly.
